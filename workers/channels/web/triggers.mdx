<Warning>
  **Coming soon.** Triggers are not available yet. A hook does the same job today for any system that can send a web request.
</Warning>

When triggers ship, you will pick an event in a connected app, a worker, and where its answer goes, and the worker will act whenever the event happens, with no web request to set up. Until then, see [Web](/workers/channels/web) for hooks.
